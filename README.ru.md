# SkiPaste для Excel v0.9

Лёгкая надстройка для Excel, исправляющая баг со вставкой при включённом фильтре. Вставляет скопированные значения строго в видимые ячейки, пропуская скрытые строки. Поддерживает вставку нескольких столбцов из буфера обмена (разделитель — табуляция). Добавляет отмену через Ctrl+Z. Оптимизировано с массивной вставкой для больших диапазонов. Числа до 10 цифр вставляются как числа (формат "0"); более длинные числа (штрих-коды, EAN-13) вставляются как текст, чтобы не превращались в научную нотацию. Автоматическая проверка обновлений при запуске (можно отключить).

### Что делает
1. Скопируйте значения из любого источника (ячейки Excel, веб-страница, текстовый редактор)
2. Выделите начальную ячейку в целевом столбце
3. Нажмите **Ctrl+Shift+P** или кнопку **"Paste to visible"** на ленте (или ПКМ → **"SP: Paste to visible cells"**)
4. SkiPaste вставляет каждую строку в следующую видимую строку, пропуская скрытые строки. Данные из нескольких столбцов (разделенные табуляцией) вставляются в соседние видимые столбцы.

### Горячая клавиша
Нажмите **Ctrl+Shift+P**, чтобы запустить SkiPaste из любого места в Excel. Работает одной левой рукой, пока надстройка загружена.

### Возможности
- Работает с одним или несколькими столбцами
- Вставляет только значения (без формул и форматирования)
- Оптимизировано под таблицы с фильтром
- Кнопка на ленте (вкладка **SkiPaste**) с подсказкой, показывающей горячую клавишу
- Пункт контекстного меню **"SP: Paste to visible cells"** при ПКМ
- Кнопка на Панели быстрого доступа (QAT)
- 64-битная совместимость (PtrSafe / VBA7)
- Валидация активного листа (пропускает диаграммы, сводные таблицы, защищённые листы)
- Проверка текста в буфере обмена (предупреждение, если буфер пуст)
- Отмена через **Ctrl+Z** (восстанавливает перезаписанные значения)

### Установка
1. Распакуйте архив
2. Нажмите правой кнопкой по **SkiPaste.xlam** → **Свойства** → поставьте галочку **Разблокировать** → **ОК**
3. Запустите **install_ru.bat** (скопирует надстройку в папку надстроек Excel)
4. Откройте Excel → **Файл > Параметры > Надстройки** > Управление: **Надстройки Excel** > **Перейти...**
5. Нажмите **Обзор...**, выберите **SkiPaste.xlam**, поставьте галочку и нажмите **ОК**

## История версий

- **v0.9** — Автоматическая проверка обновлений при запуске через GitHub API (можно отключить константой `SKIPASTE_CHECK_UPDATES`)
- **v0.8** — Умный формат чисел: до 10 цифр как числа (формат "0"), длиннее (штрих-коды/EAN) как текст, чтобы не было научной нотации
- **v0.7** — Текстовый формат вставленных данных (штрих-коды/EAN не показываются как 4,64005E+12), исправлена ошибка 1004 при закрытии Excel
- **v0.6** — Массивная вставка (быстрее на больших диапазонах), горячая клавиша изменена на Ctrl+Shift+P
- **v0.5** — Вставка нескольких столбцов (табуляция), отмена через Ctrl+Z
- **v0.4** — Пункт контекстного меню (ПКМ → "SP: Paste to visible cells"), валидация активного листа, проверка текста в буфере обмена
- **v0.3** — 64-битная совместимость (PtrSafe / VBA7), константа версии `SKIPASTE_VERSION`
- **v0.2** — Горячая клавиша `Ctrl+Shift+S`, подсказка на кнопке ленты
- **v0.1** — Первый релиз
