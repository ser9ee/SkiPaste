# SkiPaste для Excel v0.4

Лёгкая надстройка для Excel, исправляющая баг со вставкой при включённом фильтре. Вставляет скопированные значения строго в видимые ячейки, пропуская скрытые строки.

## Скачать

[Скачать SkiPaste.zip](https://github.com/ser9ee/SkiPaste/releases/latest/download/SkiPaste.zip) или клонировать репозиторий.

## Установка

1. Скачайте и распакуйте архив.
2. Нажмите правой по **SkiPaste.xlam** → **Свойства** → внизу поставьте галочку **Разблокировать** → **ОК**.
3. Запустите **install_ru.bat** (скопирует надстройку в папку надстроек Excel).
4. Откройте Excel → **Файл > Параметры > Надстройки** > Управление: **Надстройки Excel** > **Перейти...**
5. Нажмите **Обзор...**, выберите **SkiPaste.xlam**, поставьте галочку и нажмите **ОК**.
6. На ленте должна появиться вкладка **SkiPaste**.

### Если вкладка на ленте не появилась

Макрос `RunSkiPaste` работает и без ленты. Добавьте его на панель быстрого доступа:

- Excel → стрелка на панели быстрого доступа → **Другие команды**
- Выберите **Макросы** → найдите **RunSkiPaste** → **Добавить** → **ОК**

## Использование

1. Скопируйте столбец значений (Ctrl+C)
2. Выделите верхнюю видимую ячейку в целевом столбце
3. Нажмите **SkiPaste > Вставить в видимые ячейки** (или ПКМ → **SP: Paste to visible cells**, или кнопка на панели быстрого доступа)

### Горячая клавиша

Нажмите **Ctrl+Shift+S**, чтобы запустить SkiPaste из любого места в Excel (одной левой рукой).  
Ярлык активен, пока надстройка загружена.

## Особенности

- Работает только с одним столбцом
- Вставляет только значения (без формул и форматирования)
- Оптимизировано под таблицы с фильтром
