# SkiPaste for Excel

Оптимизированная надстройка для Excel, которая исправляет баг с вставкой при активном фильтре.

## Как работает
При включённом фильтре стандартная вставка `Ctrl+V` затирает скрытые строки. SkiPaste вставляет скопированный столбец только в видимые ячейки.

## Установка
1. Скачайте архив/репозиторий
2. Нажмите правой по `SkiPaste.xlam` → Свойства → Разблокировать
3. Запустите `install.bat` (скопирует в `%AppData%\Microsoft\AddIns\`)
4. Excel → Файл → Параметры → Надстройки → Надстройки Excel → Перейти → Обзор → выбрать `SkiPaste.xlam` → ОК
5. На ленте появится вкладка `SkiPaste`

## Использование
1. Скопируйте столбец значений (`Ctrl+C`)
2. Выделите верхнюю видимую ячейку в целевом столбце
3. Нажмите `SkiPaste` → `Вставить в видимые ячейки`
